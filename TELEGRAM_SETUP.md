# Saen — настройка Telegram уведомлений

## Что это
Когда клиент оформляет предзаказ в PWA, тебе приходит уведомление в Telegram:

```
🆕 Новый предзаказ № 4287
Edit N°I — Hifz

1. Augustinus Bader · The Rich Cream — 1 887 000 сум
2. Byredo · Mojave Ghost — 3 974 000 сум

💰 Итого: 5 861 000 сум
   Предоплата 50%: 2 930 500 сум

👤 Алия Каримова
📱 +998 90 123 45 67
✉️ aliya@example.com

📍 Доставка: Юнусабад, ул. Амира Темура 78, кв. 12

Saen · 19.05.2026, 14:32
```

## Шаги настройки (5 минут)

### 1. Создай Telegram-бота
- Открой Telegram, найди `@BotFather`
- Напиши `/newbot`
- Имя: `Saen Orders`
- Username: `saen_orders_bot` (или любой свободный, должен оканчиваться на `_bot`)
- Бот пришлёт тебе **TOKEN** вида `7234567890:AAH-abcDEFghij...`
- Сохрани этот токен

### 2. Узнай свой chat_id
- Найди в Telegram твоего нового бота (по username из шага 1)
- Напиши ему `/start`
- Открой в браузере: `https://api.telegram.org/bot<TOKEN>/getUpdates`
  (замени `<TOKEN>` на твой)
- В ответе найди `"chat":{"id":123456789` — это твой **CHAT_ID**

### 3. Добавь в Vercel
- Залогинься в Vercel → твой проект Saen
- Settings → Environment Variables → Add new
- Добавь две переменные:
  - `TELEGRAM_BOT_TOKEN` = твой токен из шага 1
  - `TELEGRAM_CHAT_ID` = твой chat_id из шага 2
- Сохрани, передеплой проект (Deployments → Redeploy)

### 4. Проверь
- Открой PWA, добавь позицию в корзину, оформи тестовый заказ
- В Telegram должно прийти уведомление

## Если что-то не работает

**Не приходит ничего:**
- Проверь Settings → Environment Variables что оба значения заданы
- Проверь что проект передеплоен после добавления env vars
- Открой DevTools в браузере → Network → найди запрос к `/api/notify-order` — что в ответе

**Ошибка 500:** Vercel не нашёл переменные. Передеплой.

**Ошибка 502 "Telegram delivery failed":** Токен или chat_id неверные. Проверь.

## Безопасность
- Токен и chat_id хранятся ТОЛЬКО в Vercel, не в коде
- Браузер клиента их никогда не видит
- Endpoint `/api/notify-order` принимает только POST с JSON

## Что делает приложение при сбоях
- Если интернет пропал в момент отправки — заказ остаётся в localStorage клиента
- При следующем открытии приложение пробует отправить ещё раз (`retryPendingOrders`)
- Клиент видит подтверждение независимо от того, дошло ли уведомление — это правильно, потому что заказ всё равно сохранён
