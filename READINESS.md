## Условия запуска и ограничения

Полный список конкретных env и параметров Vercel, порядок публикации/отката и инструкция сверки — [DEPLOY.md](DEPLOY.md), пример — [.env.example](.env.example).
По умолчанию API закрыт; одного существующего Telegram token недостаточно.
Redis должен сохранять записи без TTL/вытеснения; резервирование и права доступа проверяются владельцем.

Telegram не предоставляет идемпотентную отправку, поэтому exactly-once доставку при сбоях обещать нельзя. Реализована однократная автоматическая попытка после устойчивой отметки; неясные результаты требуют человека.
Фоновая доставка с закрытым iOS PWA не обещается: очередь повторяется при открытом/возобновлённом приложении. Первое посещение требует сети для кеширования.
Удаление данных браузера/приложения до серверного приёма удалит локальную очередь; при отказе записи оформление блокируется.
Старые четырёхзначные заказы требуют сверки с менеджером, чтобы повторный выпуск PWA не породил дубликаты.

Коммерческие цены/наличие, бесплатная доставка и дата запуска перенесены из исходника и не подтверждены владельцем. Оплата остаётся ручной после связи с менеджером; автоматический платёжный сервис не добавлялся.
Лендинг содержит формы подписки с демонстрационным «Спасибо» без backend; их нельзя считать сбором подписчиков. Это не путь оформления заказа; отдельный backend подписок в этот PR не включён.
Production deployment, DNS/HTTPS, реальные права бота/чата, Redis plan/backup и доставка реального уведомления не подтверждены. Боевой контрольный заказ требует отдельного разрешения.
