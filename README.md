# Saen — saen.uz

PWA-маркетплейс премиальной косметики для Ташкента.
В прежнем README запуск Edit N°I (Hifz) указан на **1 ноября 2026**.
Дата и коммерческие условия требуют подтверждения владельцем; технические изменения её не подтверждают.

## Оформление заказов

- `/` — лендинг; `/app/` — PWA с каталогом, корзиной и историей.
- `app/catalog.js` — общий источник цен в UZS для PWA и сервера. Любое изменение цены/доступности требует новой `version` и версии service worker.
- `/api/notify-order` — Edge Function: строгая схема, серверный пересчёт, ограничения частоты, атомарное сохранение в Upstash Redis **до** уведомления Telegram.
- UUID и отпечаток содержимого предотвращают повторную обработку. Принятые заказы воспроизводятся с тем же ответом после обновления каталога.
- Клиент сохраняет заказ до запроса и показывает принятие только после ответа сервера. Офлайн-очередь восстанавливается при запуске, событии `online`, возврате во вкладку и периодической проверке открытой страницы.
- При потере ответа Telegram заказ сохраняется и требует ручной сверки. Автоматической повторной отправки Telegram нет: API Telegram не предоставляет ключ идемпотентности.

По умолчанию приём заказов закрыт. Для публикации обязательны настройки из [DEPLOY.md](DEPLOY.md).
Фактические настройки Vercel и Telegram этим репозиторием не подтверждены.

## Проверки

Node.js 24; `npm ci`, `npm test`, `npm run check`.
Для интеграционных тестов нужен локальный `redis-server`/`redis-cli`; CI требует их наличия.
Для браузеров: `npx playwright install --with-deps chromium webkit`, `npm run test:e2e`.
Все тесты изолированы: Telegram заменён заглушкой; боевые API и базы не используются.

`npm run check` создаёт `public/` только из лендинга и файлов `app/`.
Исходники сервера, тесты и инструкции не публикуются как статические файлы.
Подробный результат проверки — [READINESS.md](READINESS.md).
