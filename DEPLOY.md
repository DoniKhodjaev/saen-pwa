# Деплой Saen — пошаговая инструкция

Цель: за ~30 минут получить рабочий `saen.uz` с приёмом заказов в Telegram.

---

## ЧАСТЬ I — Загрузка кода в GitHub (5 мин)

Ты уже создал Vercel и подключил GitHub. Теперь нужен **репозиторий с кодом**.

### Если репозитория ещё нет

1. Зайди на **github.com** → справа сверху `+` → `New repository`
2. Имя: `saen-website` (или любое)
3. Visibility: **Private** (приватный — никому не виден)
4. **НЕ** ставь галочки «Add README», «Add .gitignore» — пусть будет пустой
5. Нажми `Create repository`
6. На следующей странице **скопируй URL** вида `https://github.com/DoniKhodjaev/saen-website.git`

### Загрузка файлов

**Самый быстрый способ — через веб-интерфейс GitHub:**

1. На странице нового пустого репозитория нажми **`uploading an existing file`** (синяя ссылка в тексте)
2. Перетяни **всё содержимое** папки `saen-website` (которую ты скачал из чата) — **не саму папку, а файлы и подпапки внутри**:
   ```
   index.html
   README.md
   TELEGRAM_SETUP.md
   vercel.json
   api/          (целиком, с notify-order.js внутри)
   app/          (целиком, со всеми файлами PWA)
   ```
3. Внизу — `Commit changes` → жми зелёную кнопку

После этого репозиторий выглядит так:

```
saen-website/
├── README.md
├── TELEGRAM_SETUP.md
├── vercel.json
├── index.html
├── api/
│   └── notify-order.js
└── app/
    ├── index.html
    ├── manifest.json
    ├── sw.js
    ├── icon-192.png
    └── icon-512.png
```

**Альтернатива через GitHub Desktop** (если предпочитаешь): создай локально папку с этими файлами, открой через GitHub Desktop → `Publish repository`.

## ЧАСТЬ II — Подключение к Vercel (3 мин)

1. Зайди в **Vercel** → твой dashboard
2. Жми `Add New...` → `Project`
3. Из списка GitHub-репозиториев выбери **`saen-website`** (или то имя что ты дал) → `Import`
4. На странице настройки:
   - **Framework Preset:** `Other` (так как у нас чистый HTML/JS без сборки)
   - **Root Directory:** оставь как есть (`.`)
   - **Build Command:** оставь пустым
   - **Output Directory:** оставь пустым
5. **НЕ** жми `Deploy` пока — сначала добавим переменные

### Environment Variables (важно!)

На той же странице раздел `Environment Variables`:

| Name | Value |
|---|---|
| `TELEGRAM_BOT_TOKEN` | (заполним в части III) |
| `TELEGRAM_CHAT_ID` | (заполним в части III) |

Можешь добавить **пустые** значения сейчас и обновить позже — главное чтобы переменные **существовали** до первого деплоя.

Теперь жми **`Deploy`**.

Через 30—60 секунд получишь URL вида `saen-website-abc123.vercel.app`. Это уже работает — лендинг открывается, PWA доступен через `/app`.

## ЧАСТЬ III — Telegram-бот (5 мин)

### Создай бота

1. В Telegram найди **`@BotFather`** → напиши `/newbot`
2. На вопрос «Alright, a new bot. How are we going to call it?»:
   - **Name:** `Saen Orders` (это видимое имя, можно любое)
3. На вопрос «Now let's choose a username...»:
   - **Username:** `saen_orders_bot` (если занято — попробуй `saen_orders_uz_bot`)
   - Должен оканчиваться на `_bot`
4. BotFather пришлёт сообщение с **токеном** — длинная строка вида:
   ```
   7234567890:AAH-abcDEFghijklmnoPQRsTUv_wXYZ12345
   ```
   **Сохрани** этот токен — это значение для `TELEGRAM_BOT_TOKEN`.

### Узнай свой chat_id

1. В Telegram найди **своего нового бота** (по username, который ты выбрал)
2. Напиши ему **`/start`** или любое сообщение (важно — должно быть хотя бы одно сообщение от тебя)
3. Открой в браузере URL (вставь свой токен):
   ```
   https://api.telegram.org/bot7234567890:AAH-abc.../getUpdates
   ```
4. В ответе найди блок:
   ```json
   "chat": {
     "id": 123456789,
     ...
   }
   ```
5. Число — это твой **chat_id**. Сохрани его — это значение для `TELEGRAM_CHAT_ID`.

### Добавь в Vercel

1. Vercel → твой проект → `Settings` → `Environment Variables`
2. Найди `TELEGRAM_BOT_TOKEN` — `Edit` → вставь токен → `Save`
3. Найди `TELEGRAM_CHAT_ID` — `Edit` → вставь chat_id → `Save`
4. **Перезапусти деплой:** `Deployments` (сверху) → справа от последнего деплоя `...` → `Redeploy`

Через минуту проект задеплоится с переменными.

## ЧАСТЬ IV — Проверка (3 мин)

1. Открой **`saen-website-abc123.vercel.app`** на телефоне (URL из Vercel)
2. **Лендинг** должен открыться нормально
3. Прокрути до блока **«Установите приложение»** → нажми кнопку
   - На Android — должен появиться системный диалог установки
   - На iPhone — должна выехать инструкция «два шага в Safari»
4. Перейди по `/app` (или через кнопку) — **PWA откроется**
5. Пройди онбординг → каталог → добавь 2 позиции в корзину → оформи тестовый заказ
6. **В Telegram должно прийти уведомление** с деталями заказа

Если уведомление пришло — **готово**. Можно подключать домен.

## ЧАСТЬ V — Подключение домена saen.uz (5 мин)

Этот шаг можно отложить и сначала тестировать на `*.vercel.app`.

1. Vercel → проект → `Settings` → `Domains`
2. Введи `saen.uz` → `Add`
3. Vercel покажет инструкцию — нужно настроить DNS у регистратора домена

### Если домен куплен на uz-host или другом узбекском регистраторе

В панели управления доменом найди раздел `DNS` или `DNS-записи`. Удали существующие A/CNAME записи для `@` и `www`, добавь новые:

| Type | Name | Value |
|---|---|---|
| A | @ | `76.76.21.21` |
| CNAME | www | `cname.vercel-dns.com` |

(Точные значения Vercel покажет тебе на странице добавления домена — используй ИХ, не эти из примера)

DNS-распространение занимает от 5 минут до 24 часов. Vercel автоматически выпустит SSL-сертификат когда DNS заработает.

## Если что-то сломалось

### «Build failed» на Vercel
Не должно быть — у нас чистый HTML без сборки. Если упало — проверь что структура файлов в репозитории точно такая как описано выше. Особенно — что `api/notify-order.js` в корне репо, не в `app/api/`.

### Заказ не приходит в Telegram
1. Открой PWA в браузере, DevTools (F12) → вкладка `Network` → оформи заказ
2. Найди запрос на `/api/notify-order` — посмотри ответ:
   - **500** — Vercel не нашёл env vars. Проверь Settings → Environment Variables, передеплой.
   - **502** — токен или chat_id неверные. Проверь.
   - **400** — формат заказа сломан. Скинь ответ — посмотрю.
3. Если запроса вообще нет — проверь что PWA на новом URL (не из старого кэша)

### PWA не устанавливается на iPhone
Это нормально — Apple запрещает программную установку, появляется инструкция. Это работает как задумано.

### PWA не устанавливается на Android
- Должен быть HTTPS — Vercel это даёт автоматом ✓
- Должен быть `manifest.json` — есть ✓
- Должен быть service worker — есть ✓
- Если кнопка `Установить` не реагирует — открой через Chrome (не другой браузер) и проверь DevTools → Application → Manifest

### Обновления PWA не приходят клиентам
- При каждом деплое меняй строку `const VERSION = 'saen-v3-2026-05-19'` в `app/sw.js` (хотя бы дату)
- Без смены VERSION service worker не перерегистрируется
